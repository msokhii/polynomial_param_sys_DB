Parametric Linear Systems Database

A benchmark collection for solving A(y)x=b(y) over finite fields and reconstructing multivariate rational solutions.

Inclusion rule. Each family is linear in x, scalable, and generically nonsingular. Unless stated otherwise, the right-hand side is a fixed integer vector with no symbolic parameters.

N is the number of unknowns/equations. m counts symbolic parameters only. Counts marked by graph/mesh quantities are topology dependent. “Max input degree” is total degree in the chosen independent benchmark parameters; several physical specializations intentionally identify affine dynamic parameters with products such as ω²m or sσ only after reconstruction.

Strong balanced first suite: S1, S4, P1, P2, P13, P19, P31, P35. These cover dense repeated-entry structure, large-N/fixed-m scaling, hard graph denominators, tiny-m PDE scaling, saddle points, circuit descriptors, optimization KKT matrices, and general model-reduction pencils.

System definitions

S1

Symmetric Toeplitz

primary dense benchmarktop
N=n · m=n · degree=1 · dense
Example · n = 4
\[ A=\begin{bmatrix} t_0&t_1&t_2&t_3\\ t_1&t_0&t_1&t_2\\ t_2&t_1&t_0&t_1\\ t_3&t_2&t_1&t_0 \end{bmatrix},\qquad b=\begin{bmatrix}1\\2\\3\\4\end{bmatrix}. \]

Parameters. t₀,…,tₙ₋₁.

Suggested sweep. n = 8, 12, 16, 20, then increase until probe count or reconstruction dominates.

Why use it. This is the cleanest baseline for the whole database: the matrix is dense, every entry is linear in the parameters, the parameter count grows with n, and setting t₀=1 with all other tᵢ=0 gives the identity, so the family is generically nonsingular.

S2

General Toeplitz

many parameterstop
N=n · m=2n−1 · degree=1 · dense
Example · n = 4
\[ A=\begin{bmatrix} t_0&t_1&t_2&t_3\\ t_{-1}&t_0&t_1&t_2\\ t_{-2}&t_{-1}&t_0&t_1\\ t_{-3}&t_{-2}&t_{-1}&t_0 \end{bmatrix},\qquad b=\begin{bmatrix}1\\2\\3\\4\end{bmatrix}. \]

Parameters. t₋ₙ₊₁,…,t₋₁,t₀,t₁,…,tₙ₋₁.

Why use it. It keeps the same dense Toeplitz geometry as S1 but roughly doubles the parameter count. Compare S1 and S2 at the same n to isolate the cost of additional variables in the reconstructed rational functions.

S3

Hankel

dense structuredtop
N=n · m=2n−1 · degree=1 · dense
Example · n = 4
\[ A=\begin{bmatrix} h_0&h_1&h_2&h_3\\ h_1&h_2&h_3&h_4\\ h_2&h_3&h_4&h_5\\ h_3&h_4&h_5&h_6 \end{bmatrix},\qquad b=\begin{bmatrix}1\\2\\3\\4\end{bmatrix}. \]

Parameters. h₀,…,h₂ₙ₋₂. Choosing hₙ₋₁=1 and all other hᵢ=0 gives the reversal permutation matrix, hence the determinant is not identically zero.

Why use it. It has the same parameter count as S2 but a different repeated-entry pattern. This makes S2 versus S3 a useful structure comparison without changing n or m.

S4

Banded Toeplitz

large-N benchmarktop
N=n · m=2w+1 · degree=1 · sparse
Example · n = 5, w = 1
\[ A=\begin{bmatrix} t_0&t_1&0&0&0\\ t_{-1}&t_0&t_1&0&0\\ 0&t_{-1}&t_0&t_1&0\\ 0&0&t_{-1}&t_0&t_1\\ 0&0&0&t_{-1}&t_0 \end{bmatrix}. \]

Parameters. t₋w,…,t₀,…,t_w. Treat bandwidth w as a second benchmark knob.

Why use it. This is the simplest way to make the numerical solve large without simultaneously making the interpolation dimension large. Hold w fixed and grow n. It is therefore one of the most important complements to S1.

S5

Block Toeplitz with Toeplitz blocks (BTTB)

2-D structuredtop
N=q² · m=(2q−1)² · degree=1 · dense
Example · q = 2
\[ A=\begin{bmatrix} \tau_{0,0}&\tau_{0,1}&\tau_{1,0}&\tau_{1,1}\\ \tau_{0,-1}&\tau_{0,0}&\tau_{1,-1}&\tau_{1,0}\\ \tau_{-1,0}&\tau_{-1,1}&\tau_{0,0}&\tau_{0,1}\\ \tau_{-1,-1}&\tau_{-1,0}&\tau_{0,-1}&\tau_{0,0} \end{bmatrix}. \]
Rows and columns are ordered by the 2×2 grid points.

Parameters. One τa,b for each offset −(q−1)≤a,b≤q−1.

Why use it. This is the natural two-dimensional analogue of general Toeplitz. The matrix dimension grows quadratically in q while the number of shift parameters also grows on the order of N. It is a strong dense many-parameter stress test.

S6

Generic tridiagonal / continuant family

sparse many-parametertop
N=n · m=3n−2 · degree=1 · sparse
Example · n = 4
\[ A=\begin{bmatrix} d_1&u_1&0&0\\ l_1&d_2&u_2&0\\ 0&l_2&d_3&u_3\\ 0&0&l_3&d_4 \end{bmatrix}. \]

Parameters. d₁,…,dₙ, u₁,…,uₙ₋₁, l₁,…,lₙ₋₁.

Why use it. Parameter count is very high relative to matrix sparsity. It separates “many interpolation variables” from “expensive dense finite-field solve.” The determinant obeys the standard continuant recurrence, so this is also easy to validate independently.

R1

Sylvester resultant matrix

algebraic benchmarktop
N=r+s · m=r+s+2 · degree=1 · structured
Example · r = s = 2
\[ A=\operatorname{Sylv}(f,g)= \begin{bmatrix} a_2&a_1&a_0&0\\ 0&a_2&a_1&a_0\\ b_2&b_1&b_0&0\\ 0&b_2&b_1&b_0 \end{bmatrix}. \]
Here \(f=a_0+a_1z+a_2z^2\) and \(g=b_0+b_1z+b_2z^2\).

Parameters. a₀,…,aᵣ,b₀,…,bₛ. For a balanced sweep use r=s.

Why use it. The determinant is the resultant of two generic polynomials. This gives a very natural algebraic denominator rather than an arbitrary random one, and the family scales directly by increasing the polynomial degrees.

R2

Bézout matrix of two generic polynomials

degree-2 inputtop
N=q · m=2q+2 · degree=2 · dense
Example · q = 2
\[ B(f,g)=\begin{bmatrix} a_1b_0-a_0b_1 & a_2b_0-a_0b_2\\ a_2b_0-a_0b_2 & a_2b_1-a_1b_2 \end{bmatrix}. \]

Why use it. Unlike most families here, the matrix entries themselves are bilinear in the parameters. This is a controlled test of the effect of input degree 2 while retaining a canonical resultant structure.

R3

Companion resolvent

large sparse controltop
N=n · m=n+1 · degree=1 · sparse
Example · n = 4
\[ sI-C=\begin{bmatrix} s&0&0&a_0\\ -1&s&0&a_1\\ 0&-1&s&a_2\\ 0&0&-1&s+a_3 \end{bmatrix}. \]

Parameters. s,a₀,…,aₙ₋₁.

Why use it. This is a deliberately structured control case: N can be pushed very high, the matrix has only O(N) nonzeros, and the exact denominator is known. It is useful for checking whether failures are caused by your reconstruction machinery rather than by an intrinsically difficult matrix family.

P1

Grounded weighted q×q grid Laplacian

graph / hard multivariatetop
N=q²−1 · m=2q(q−1) · degree=1 · nnz=≈ 5N
Example · q = 2, one corner grounded
\[ A=\begin{bmatrix} w_1+w_2&-w_1&-w_2\\ -w_1&w_1+w_3&0\\ -w_2&0&w_2+w_4 \end{bmatrix}. \]

Parameters. One independent edge weight for each of the 2q(q−1) grid edges.

Suggested sweep. q=4,5,6,8.

Why use it. The determinant of the grounded Laplacian is the weighted spanning-tree polynomial. This is an unusually hard output-complexity test despite the sparse five-point matrix.

P2

2-D convection–diffusion–reaction finite difference

PDE / tiny parameter counttop
N=q² · m=3 · degree=1 · nnz=≈ 5N
Example · q = 2
\[ A=\begin{bmatrix} c&e&s&0\\ w&c&0&s\\ n&0&c&e\\ 0&n&w&c \end{bmatrix}, \quad \begin{aligned} c&=8+2\gamma,\\ e&=-2+\alpha,\quad w=-2-\alpha,\\ n&=-2+\beta,\quad s=-2-\beta. \end{aligned} \]

Parameters. α is x-convection, β is y-convection, and γ is a reaction/shift parameter.

Suggested sweep. q=8,12,16,20.

Why use it. Only three interpolation variables are present no matter how large the grid becomes, so this isolates repeated finite-field solve cost from interpolation dimension.

P3

RC ladder nodal admittance

circuits / tridiagonaltop
N=n · m=2n+3 · degree=2 · nnz=3n−2
Example · n = 3
\[ A=\begin{bmatrix} y_1+y_2&-y_2&0\\ -y_2&y_2+y_3&-y_3\\ 0&-y_3&y_3+y_4 \end{bmatrix},\qquad y_i=g_i+s c_i. \]

Parameters. Laplace parameter s, conductances g_i, and capacitances c_i.

Suggested sweep. n=20,40,80,160.

Why use it. A real transfer-function family with O(n) component parameters. Products s c_i make the entries polynomial of degree two while the numerical matrix stays tridiagonal.

P4

Mass–spring chain dynamic stiffness (affine reparameterization)

mechanics / affinetop
N=n · m=2n+1 · degree=1 · nnz=3n−2
Example · n = 3
\[ A=\begin{bmatrix} k_1+k_2-d_1&-k_2&0\\ -k_2&k_2+k_3-d_2&-k_3\\ 0&-k_3&k_3+k_4-d_3 \end{bmatrix}. \]

Parameters. k_1,…,k_{n+1}, d_1,…,d_n. The d_i are independent interpolation variables in the affine benchmark.

Suggested sweep. n=20,40,80,160.

Why use it. This keeps every matrix entry affine in the symbolic parameters while retaining the exact mass–spring dynamic-stiffness specialization after setting d_i=ω²m_i.

P5

Birth–death Markov-chain reachability

probability / tridiagonaltop
N=n · m=2n · degree=1 · nnz=3n−2
Example · n = 3
\[ A=\begin{bmatrix} p_1+q_1&-p_1&0\\ -q_2&p_2+q_2&-p_2\\ 0&-q_3&p_3+q_3 \end{bmatrix},\qquad b=\begin{bmatrix}0\\0\\p_3\end{bmatrix}. \]

Parameters. Birth/right probabilities p_i and death/left probabilities q_i.

Suggested sweep. n=20,40,80,160.

Why use it. The unknowns are hitting probabilities. Both A and b are affine in 2n parameters and every finite-field solve is tridiagonal.

P6

General grounded resistor / conductance network

circuits / graphstop
N=|V|−1 · m=|E| · degree=1 · nnz=O(|E|)
Example · 3 free nodes
\[ A=\begin{bmatrix} g_{10}+g_{12}+g_{13}&-g_{12}&-g_{13}\\ -g_{12}&g_{20}+g_{12}+g_{23}&-g_{23}\\ -g_{13}&-g_{23}&g_{30}+g_{13}+g_{23} \end{bmatrix}. \]
\(g_{i0}\) denotes a conductance from node \(i\) to the grounded node.

Parameters. One conductance g_e per graph edge.

Suggested sweep. paths, trees, expanders, random sparse graphs.

Why use it. This is Kirchhoff nodal analysis in its most general scalable form. Varying topology while keeping the same edge-count scaling separates graph structure from parameter count.

P7

DC power-flow network

power systems / Laplaciantop
N=n_bus−1 · m=n_line · degree=1 · nnz=O(n_line)
Example · 3 non-slack buses
\[ B_{\mathrm{bus}}=\begin{bmatrix} b_{10}+b_{12}+b_{13}&-b_{12}&-b_{13}\\ -b_{12}&b_{20}+b_{12}+b_{23}&-b_{23}\\ -b_{13}&-b_{23}&b_{30}+b_{13}+b_{23} \end{bmatrix}. \]
Bus 0 is the slack bus.

Parameters. One branch susceptance b_ℓ per transmission line; P is a fixed injection vector.

Suggested sweep. radial, mesh, IEEE-like synthetic grids.

Why use it. The DC approximation produces a grounded weighted network matrix. It is algebraically close to P6 but is worth retaining as a power-system application with realistic sparse graph topologies.

P8

1-D variable-conductivity diffusion / heat equation

PDE / tridiagonaltop
N=n · m=n+1 · degree=1 · nnz=3n−2
Example · n = 3
\[ A=\begin{bmatrix} \kappa_1+\kappa_2&-\kappa_2&0\\ -\kappa_2&\kappa_2+\kappa_3&-\kappa_3\\ 0&-\kappa_3&\kappa_3+\kappa_4 \end{bmatrix}. \]

Parameters. One conductivity/transmissibility parameter per cell face.

Suggested sweep. n=50,100,200,400.

Why use it. A canonical variable-coefficient elliptic PDE with an affine tridiagonal stiffness matrix. It is the PDE analogue of a weighted path graph.

P9

2-D anisotropic variable-coefficient diffusion

PDE / many local coefficientstop
N=q² · m=2q(q+1) · degree=1 · nnz=≈ 5N
Example · q = 2
\[ A=\begin{bmatrix} d_1&-h_1&-v_1&0\\ -h_1&d_2&0&-v_2\\ -v_1&0&d_3&-h_2\\ 0&-v_2&-h_2&d_4 \end{bmatrix}. \]
Each \(d_i\) is the sum of the horizontal and vertical face coefficients incident to that cell.

Parameters. Independent horizontal and vertical face diffusion coefficients, including boundary faces.

Suggested sweep. q=4,6,8,10.

Why use it. A finite-volume/finite-difference diffusion operator with O(N) symbolic coefficients and a five-point sparse pattern. It is a natural local-material uncertainty benchmark.

P10

Thermal model with parametric Robin / film coefficients

thermal / real MOR benchmarktop
N=mesh DOFs · m=r · degree=1 · nnz=sparse FEM
Example · N = 3, r = 2
\[ K(h)=\begin{bmatrix} k_{11}+h_1r^{(1)}_{11}+h_2r^{(2)}_{11}&k_{12}+h_1r^{(1)}_{12}+h_2r^{(2)}_{12}&k_{13}+h_1r^{(1)}_{13}+h_2r^{(2)}_{13}\\ \ast&k_{22}+h_1r^{(1)}_{22}+h_2r^{(2)}_{22}&k_{23}+h_1r^{(1)}_{23}+h_2r^{(2)}_{23}\\ \ast&\ast&k_{33}+h_1r^{(1)}_{33}+h_2r^{(2)}_{33} \end{bmatrix}. \]
The \(\ast\) entries follow the corresponding assembled FEM symmetry.

Parameters. Film/heat-transfer coefficients h_j on r boundary regions.

Suggested sweep. refine mesh; r=3,6,12 interfaces.

Why use it. This form occurs directly in boundary-condition-independent thermal models. The Oberwolfach/SuiteSparse model-reduction collection contains this exact affine parameter idea for chip and microthruster thermal models.

P11

Transient thermal descriptor / Laplace-domain heat model

thermal / descriptor penciltop
N=mesh DOFs · m=r+1 · degree=1 · nnz=sparse FEM
Example · N = 3, one material parameter
\[ A(s,\kappa)=\begin{bmatrix} se_{11}+k_{11}^{(0)}+\kappa k_{11}^{(1)}&se_{12}+k_{12}^{(0)}+\kappa k_{12}^{(1)}&se_{13}+k_{13}^{(0)}+\kappa k_{13}^{(1)}\\ se_{21}+k_{21}^{(0)}+\kappa k_{21}^{(1)}&se_{22}+k_{22}^{(0)}+\kappa k_{22}^{(1)}&se_{23}+k_{23}^{(0)}+\kappa k_{23}^{(1)}\\ se_{31}+k_{31}^{(0)}+\kappa k_{31}^{(1)}&se_{32}+k_{32}^{(0)}+\kappa k_{32}^{(1)}&se_{33}+k_{33}^{(0)}+\kappa k_{33}^{(1)} \end{bmatrix}. \]

Parameters. Frequency/Laplace parameter s and r material or boundary coefficients κ_j.

Suggested sweep. N=10³–10⁵; r small.

Why use it. Thermal MEMS and chip models routinely produce very large sparse capacity/conductivity matrix pairs. The affine descriptor form is ideal for a large-N parametric benchmark.

P12

Darcy / groundwater / single-phase reservoir pressure

porous media / graph-liketop
N=cells or nodes · m=faces + wells · degree=1 · nnz=≈ stencil size × N
Example · 3-cell chain
\[ A=\begin{bmatrix} T_{12}+w_1&-T_{12}&0\\ -T_{12}&T_{12}+T_{23}+w_2&-T_{23}\\ 0&-T_{23}&T_{23}+w_3 \end{bmatrix}. \]

Parameters. Face transmissibilities T_e and optional well/source linear coefficients w_i.

Suggested sweep. 1-D, 2-D, layered grids.

Why use it. Finite-volume Darcy pressure equations have the same conservation skeleton as a weighted Laplacian, but heterogeneous permeability and wells give a canonical petroleum/groundwater interpretation.

P13

Variable-viscosity Stokes mixed finite-element system

fluid / saddle pointtop
N=n_u+n_p−gauge · m=r · degree=1 · nnz=sparse block
Example · 2 velocity DOFs + 1 pressure DOF
\[ \begin{bmatrix} a_{11}(\nu)&a_{12}(\nu)&b_1\\ a_{21}(\nu)&a_{22}(\nu)&b_2\\ b_1&b_2&0 \end{bmatrix} \begin{bmatrix}u_1\\u_2\\p\end{bmatrix} =\begin{bmatrix}f_1\\f_2\\0\end{bmatrix}. \]

Parameters. Piecewise-constant viscosities ν_j on r regions.

Suggested sweep. mesh refinements; r=1,4,16 regions.

Why use it. The Stokes equations produce a canonical sparse saddle-point matrix. Parameterizing viscosity makes the velocity block affine while retaining the difficult indefinite block structure.

P14

Mixed Darcy saddle-point system

porous media / saddle pointtop
N=n_flux+n_p · m=r · degree=1 · nnz=sparse block
Example · 2 flux DOFs + 1 pressure DOF
\[ \begin{bmatrix} m_{11}(\rho)&m_{12}(\rho)&b_1\\ m_{21}(\rho)&m_{22}(\rho)&b_2\\ b_1&b_2&0 \end{bmatrix} \begin{bmatrix}u_1\\u_2\\p\end{bmatrix} =\begin{bmatrix}f_1\\f_2\\g\end{bmatrix}. \]

Parameters. Inverse-permeability/material coefficients ρ_j.

Suggested sweep. mesh refinements; r material regions.

Why use it. This is the standard mixed finite-element Darcy saddle-point form and differs substantially from the primal pressure matrix P12.

P15

Helmholtz / acoustic frequency-response system

waves / indefinitetop
N=mesh DOFs · m=r+1 · degree=1 · nnz=sparse FEM
Example · N = 3
\[ A(z,\kappa)=\begin{bmatrix} k_{11}(\kappa)-zm_{11}&k_{12}(\kappa)-zm_{12}&k_{13}(\kappa)-zm_{13}\\ k_{21}(\kappa)-zm_{21}&k_{22}(\kappa)-zm_{22}&k_{23}(\kappa)-zm_{23}\\ k_{31}(\kappa)-zm_{31}&k_{32}(\kappa)-zm_{32}&k_{33}(\kappa)-zm_{33} \end{bmatrix}. \]

Parameters. Squared-frequency/wavenumber z and r affine material coefficients κ_j.

Suggested sweep. 1-D/2-D meshes; N=10²–10⁴.

Why use it. The shifted stiffness–mass pencil is the canonical finite-element Helmholtz solve. It creates meaningful poles near resonances while remaining polynomial and affine in the chosen parameters.

P16

Static truss / linear-elasticity stiffness system

Suggested benchmark protocol

1. Preserve the polynomial parameterization. Evaluate the declared independent benchmark parameters modulo p, build [A|b], solve, and reconstruct the rational solution. Physical identifications such as d_i=ω²m_i should be imposed only after reconstruction when the affine benchmark form is being used.

2. Keep topology and parameter count as separate knobs. For graph/PDE families, compare fixed topology with growing parameters, and fixed parameter groups with mesh refinement. This avoids confusing numerical-solve scaling with multivariate interpolation scaling.

3. Reject only genuinely bad probes. A probe should be rejected when the evaluated matrix is singular or the modular solve fails. Near-resonant physical points are irrelevant over a finite field except insofar as they land on the exact determinant hypersurface.

4. Record structure. At minimum record N, m, max input degree, nnz(A), block structure, probes, rejected probes, modular-solve time, univariate reconstruction time, multivariate reconstruction time, verification time, and total time.

5. Verify at fresh points. Substitute one or more random parameter points not used in reconstruction and check A(α)x(α)=b(α) mod p.
